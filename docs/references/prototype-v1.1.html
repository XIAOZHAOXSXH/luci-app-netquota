安全认证 · 流量独立计量

认证流程

1. 用户连接指定 Wi-Fi。
2. 设备触发网络认证页面。
3. 输入管理员分配的账号和密码。
4. 验证通过后开放网络访问。

流量规则

每个账号拥有独立月度流量额度。多个终端使用同一账号时，共用该账号额度。每个账号的结算日可自定义；上传和下载共同消耗这份额度。

体验说明

部分手机或电脑可能不会自动弹出认证页，可通过打开普通 HTTP 网页触发认证。认证页样式可根据客户品牌进行调整。

可选 1–31 日；遇到没有该日期的月份，自动使用当月最后一天。正式后端对已存在账号的默认重置日变更从其下个周期生效。

GL-MT6000 原厂固件适配

首次部署必须确认 GL.iNet 固件版本、MTK HNAT/WED 网络加速、iptables/nftables 与 openNDS 兼容性。禁止未经实测就承诺硬件加速下准确计量。

配额规则

每个账号独立周期；上传与下载分别计数，合计消耗一份月额度。多个终端登录同一账号时合并计量。基础版不含独立上传/下载限速。

关于 NetQuota

NetQuota 是面向 OpenWrt 路由器的多用户上网认证与月度流量配额管理插件。管理员可通过 LuCI 图形界面创建账号、设置流量额度和独立结算日并查看上下行流量。普通用户可在自助门户修改自己的登录密码。
