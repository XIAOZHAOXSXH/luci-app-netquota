# 管理端双流量汇总与访客用量展示

## 需求与范围

管理员需要比较实际流量与按倍率记账的总用量，判断倍率是否合适。访客只需要查询自己的已用流量、剩余额度与进度，不展示倍率、实际计数对照等管理信息。

## 实现

- 总览、账号管理、流量统计共用双汇总卡片：本周期实际总量、本周期计费总量。
- 汇总所有未删除账号各自当前结算周期，搜索、状态筛选、排序不改变总量；不是路由器 WAN 总量或历史累计。
- 直接加总账本中的 `total_bytes` 与 `billed_bytes`，避免用当前倍率重算过去用量。
- 账号列表主值保持 `billed_bytes`，新增实际用量副行；进度和剩余额度继续采用计费口径。
- 门户使用“已用流量”，值仍来自既有 `used_bytes`。移除原始上传、下载、实际合计、倍率说明；门户接口只返回查询额度所需字段。
- 不修改倍率、配额、内核断网、月度结算或数据库结构。软件版本更新为 0.6.1，便于安装升级和更新门户静态资源。

## 验证入口

- `node tests/test_usage_display.js`：生产渲染器使用实际 16.44 GB、计费 16.9 GB 等不同数据，检查两套汇总、主值、空状态及不追溯重算。
- `python -m unittest discover -s tests -p 'test_*.py'`：打包、发布元数据和路由器工具检查。
- `tools/test_on_router.py`：真实 Lua/SQLite/密码学与 HTTP/HTTPS 门户接口；验证访客接口不返回实际计数及倍率。
- `tests/browser-usage-display.js`：实机三页总量与 RPC 账本核对、筛选不改变总量、亮暗主题与 390px 布局。
- `tests/browser-portal.js`：真实访客链路登录、账户查询、退出和异常连接提示，检查页面及 API 不展示管理计费信息。
